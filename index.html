TOPIC 01

Booth's Algorithm

1. Question

Multiply two signed binary integers, represented in two's-complement form, using Booth's algorithm. The result is a signed product.

Sample input

7 -7

Sample output

-49

2. Idea in plain words

Look at the multiplier's last bit Q0 and the extra bit Q-1. A change from 0 to 1 starts a run of 1s, so add the multiplicand; a change from 1 to 0 ends a run, so subtract it. Equal bits need no add or subtract. Then arithmetic-shift the combined registers once.

Two's complement is the fixed-width binary representation used for signed integers; negative values are represented so addition and subtraction work with the same bit circuitry. An arithmetic right shift copies the sign bit as it shifts.

Think of a row of lit bulbs: a whole run of 1s can be counted by its two edges instead of adding once for every bulb.

Q0 Q-1 = 01 → A = A + M10 → A = A − M00 or 11 → no change

Every case is followed by one arithmetic shift of A, Q, Q-1.

3. Dry run

201A = 1100 + 0111 = 00110001, 1110, 0

410A = 0000 − 0111 = 10011100, 1111, 1
Result—Join A and Q: 11001111−49 in signed 8-bit two’s complement

4. Java code manual · exam version

Manual · exam version
import java.util.Scanner;

public class Main {
    private static long boothMultiply(int multiplicand, int multiplier) {
        int accumulator = 0;
        int qMinusOne = 0;
        int q = multiplier;
        int m = multiplicand;

        // One cycle for each bit in a Java int.
        for (int step = 0; step < 32; step++) {
            int q0 = q & 1;

            // A 01 boundary adds M; a 10 boundary subtracts M.
            if (q0 == 0 && qMinusOne == 1) {
                accumulator += m;
            } else if (q0 == 1 && qMinusOne == 0) {
                accumulator -= m;
            }

            // Save the old low bit before shifting the combined registers.
            qMinusOne = q & 1;
            q = (q >>> 1) | ((accumulator & 1) << 31);
            accumulator >>= 1; // Arithmetic shift keeps the sign bit.
        }

        // A and Q form the signed 64-bit product.
        return ((long) accumulator << 32) | (q & 0xFFFFFFFFL);
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int multiplicand = scanner.nextInt();
        int multiplier = scanner.nextInt();
        System.out.println(boothMultiply(multiplicand, multiplier));
    }
}

TOPIC 02

Euclid's Algorithm

1. Question

Given two integers, find their greatest common divisor (GCD): the largest non-negative integer that divides both without a remainder.

Sample input

10 15

Sample output

5

2. Idea in plain words

Replace the pair (a, b) with (b, a % b). The common divisors stay the same, but the second number gets smaller. Stop when the remainder is zero; the other number is the GCD.

It is like repeatedly keeping the leftover piece after fitting the smaller length into the larger one. The final non-zero length divides both original values.

The slide’s “prime factorization” introduction is not needed: repeated remainders are the Euclidean method.

3. Dry run

Start1015—(10, 15)
1101510(15, 10)
215105(10, 5)
31050(5, 0)
Stop50—GCD = 5

4. Java code manual · exam version

Manual · exam version
import java.math.BigInteger;
import java.util.Scanner;

public class Main {
    private static BigInteger gcdByRemainders(BigInteger a, BigInteger b) {
        // A GCD is non-negative, even when an input is negative.
        a = a.abs();
        b = b.abs();

        while (b.signum() != 0) {
            BigInteger remainder = a.remainder(b); // The Euclidean step.
            a = b;
            b = remainder;
        }
        return a;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        BigInteger a = scanner.nextBigInteger();
        BigInteger b = scanner.nextBigInteger();
        System.out.println(gcdByRemainders(a, b));
    }
}

  • BigInteger avoids abs(Integer.MIN_VALUE) overflow.

TOPIC 03

Karatsuba Algorithm

1. Question

Multiply large integers by splitting each number into high and low parts, using three recursive multiplications, then combining the results.

Sample input

1234 5678

Sample output

7006652

2. Idea in plain words

Write x = a·10m + b and y = c·10m + d. The ordinary expansion uses four products. Karatsuba gets the middle term from only one extra product:

ac, bd, and (a+b)(c+d); then ad+bc = (a+b)(c+d) − ac − bd.

It is like splitting each number into two chunks and reusing the sum of the chunks to recover the cross terms.

3. Dry run

StepValue
Split1234 = 12·100 + 34; 5678 = 56·100 + 78
ac12 × 56 = 672
bd34 × 78 = 2,652
(a+b)(c+d)46 × 134 = 6,164
Cross term6,164 − 672 − 2,652 = 2,840
Combine672·10,000 + 2,840·100 + 2,652 = 7,006,652

4. Java code manual · exam version

Manual · exam version
import java.math.BigInteger;
import java.util.Scanner;

public class Main {
    private static BigInteger karatsuba(BigInteger x, BigInteger y) {
        boolean negative = x.signum() != y.signum();
        BigInteger result = karatsubaPositive(x.abs(), y.abs());
        return negative ? result.negate() : result;
    }

    private static BigInteger karatsubaPositive(BigInteger x, BigInteger y) {
        if (x.signum() == 0 || y.signum() == 0) {
            return BigInteger.ZERO;
        }

        int digits = Math.max(x.toString().length(), y.toString().length());
        if (digits == 1) {
            // One decimal digit times one decimal digit fits in int.
            return BigInteger.valueOf(x.intValue() * y.intValue());
        }

        int half = digits / 2;
        BigInteger power = BigInteger.TEN.pow(half);

        // Divide each value into high and low decimal chunks.
        BigInteger a = x.divide(power);
        BigInteger b = x.remainder(power);
        BigInteger c = y.divide(power);
        BigInteger d = y.remainder(power);

        BigInteger ac = karatsubaPositive(a, c);
        BigInteger bd = karatsubaPositive(b, d);
        BigInteger sumProduct = karatsubaPositive(a.add(b), c.add(d));

        // Removing ac and bd leaves the two cross-products.
        BigInteger cross = sumProduct.subtract(ac).subtract(bd);

        BigInteger highPart = appendDecimalZeros(ac, 2 * half);
        BigInteger middlePart = appendDecimalZeros(cross, half);
        return highPart.add(middlePart).add(bd);
    }

    private static BigInteger appendDecimalZeros(BigInteger value, int zeros) {
        if (value.signum() == 0) {
            return BigInteger.ZERO;
        }

        // Appending decimal zeroes shifts by a power of ten without multiply().
        StringBuilder shifted = new StringBuilder(value.toString());
        for (int i = 0; i < zeros; i++) {
            shifted.append('0');
        }
        return new BigInteger(shifted.toString());
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        BigInteger x = scanner.nextBigInteger();
        BigInteger y = scanner.nextBigInteger();
        System.out.println(karatsuba(x, y));
    }
}

TOPIC 04

Longest Sequence of 1s after flipping a bit

1. Question

Given a binary sequence and permission to flip at most k zeroes to ones, find the longest contiguous sequence of ones that can result. Setting k = 1 gives the single-bit version in the topic title.

Sample input

1110001111 2

Sample output

6

2. Idea in plain words

Keep a sliding window that contains at most k zeroes. Expand its right edge one bit at a time. If it contains too many zeroes, move the left edge until it is valid again. The longest valid window is the answer.

Each zero inside a valid window can be flipped, so every bit in that window can become 1. The slide’s sample allows two flips; for exactly one allowed flip, use k = 1.

4. Java code manual · exam version

Manual · exam version
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String bits = scanner.next();
        int allowedFlips = scanner.nextInt();

        if (allowedFlips < 0) {
            throw new IllegalArgumentException("k must be non-negative");
        }

        // Reject characters outside the promised binary sequence.
        for (int i = 0; i < bits.length(); i++) {
            char bit = bits.charAt(i);
            if (bit != '0' && bit != '1') {
                throw new IllegalArgumentException("Input must contain only 0 and 1");
            }
        }

        int left = 0;
        int zeroes = 0;
        int best = 0;

        for (int right = 0; right < bits.length(); right++) {
            if (bits.charAt(right) == '0') {
                zeroes++;
            }

            // Restore the at-most-k-zeroes rule.
            while (zeroes > allowedFlips) {
                if (bits.charAt(left) == '0') {
                    zeroes--;
                }
                left++;
            }

            best = Math.max(best, right - left + 1);
        }

        System.out.println(best);
    }
}

TOPIC 05

Swap two nibbles in a byte

1. Question

Given an unsigned byte value from 0 to 255, swap its upper four bits with its lower four bits. A nibble is a group of four bits, or half of an 8-bit byte.

Sample input

100

Sample output

70

2. Idea in plain words

Mask the lower nibble with 0x0F, move it left four places, then mask the upper nibble with 0xF0 and move it right four places. OR the two pieces together.

For the slide’s 100, the 8-bit pattern is 0110 0100. The two 4-bit halves exchange positions:

Move low up(0000 0100) << 40100 0000
Upper nibble100 & 0xF00110 0000
Move upper down(0110 0000) >>> 40000 0110
Combine0100 0000 | 0000 01100100 0110 = 70

4. Java code manual · exam version

Manual · exam version
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int value = scanner.nextInt();

        // Treat the input as an unsigned 8-bit value.
        if (value < 0 || value > 255) {
            throw new IllegalArgumentException("Value must be from 0 to 255");
        }

        int lowMovedUp = (value & 0x0F) << 4;
        int highMovedDown = (value & 0xF0) >>> 4;
        int swapped = lowMovedUp | highMovedDown;
        System.out.println(swapped);
    }
}

TOPIC 06

Block Swap Algorithm

1. Question

Left-rotate an array by d positions. The first d values move to the end, in the same order.

Sample input

5 2
1 2 3 4 5

Sample output

3 4 5 1 2

2. Idea in plain words

Think of the array as two neighboring blocks, A (the first d values) and B (everything else). Swap equal-size boundary pieces from the larger block until both remaining blocks have equal size; the final swap completes the rotation.

For example, [1, 2] [3, 4, 5] becomes [3, 4, 5] [1, 2]. A left rotation is not a right rotation: normalize d first, then move the first d values to the end.

3. Dry run

StepBlocks / swapArray
StartA = [1, 2], B = [3, 4, 5]1 2 3 4 5
1Swap A with the last 2 values of B4 5 3 1 2
2Swap the remaining A piece with B’s first value3 5 4 1 2
3Swap the equal 1-value blocks3 4 5 1 2

4. Java code manual · exam version

Manual · exam version
import java.util.Scanner;

public class Main {
    private static void swapBlocks(int[] array, int first, int second, int length) {
        for (int offset = 0; offset < length; offset++) {
            int temporary = array[first + offset];
            array[first + offset] = array[second + offset];
            array[second + offset] = temporary;
        }
    }

    private static void rotateLeft(int[] array, int distance) {
        int n = array.length;
        if (n == 0) {
            return;
        }

        int d = distance % n;
        if (d < 0) {
            d += n;
        }
        if (d == 0) {
            return;
        }

        int leftBlock = d;
        int rightBlock = n - d;

        // Exchange equal-sized pieces until the remaining blocks match.
        while (leftBlock != rightBlock) {
            if (leftBlock < rightBlock) {
                swapBlocks(array, d - leftBlock,
                        d + rightBlock - leftBlock, leftBlock);
                rightBlock -= leftBlock;
            } else {
                swapBlocks(array, d - leftBlock, d, rightBlock);
                leftBlock -= rightBlock;
            }
        }

        // The two remaining equal blocks finish the left rotation.
        swapBlocks(array, d - leftBlock, d, leftBlock);
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int distance = scanner.nextInt();
        int[] array = new int[n];

        for (int i = 0; i < n; i++) {
            array[i] = scanner.nextInt();
        }

        rotateLeft(array, distance);

        StringBuilder output = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) output.append(' ');
            output.append(array[i]);
        }
        System.out.println(output);
    }
}

5. Shortcut version library-assisted

Collections.rotate

Shortcut · library-assisted
import java.util.ArrayList;
import java.util.Collections;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int distance = scanner.nextInt();
        ArrayList<Integer> values = new ArrayList<>();

        for (int i = 0; i < n; i++) {
            values.add(scanner.nextInt()); // Boxes int values for a List.
        }

        if (n > 0) {
            int d = distance % n;
            if (d < 0) d += n;
            Collections.rotate(values, -d); // Negative distance rotates left.
        }

        for (int i = 0; i < values.size(); i++) {
            if (i > 0) System.out.print(" ");
            System.out.print(values.get(i));
        }
        System.out.println();
    }
}

Java 8 API check: Oracle Java 8 Collections.rotate accepts positive or negative distances; a negative distance gives a left rotation.

Hides: Oracle documents that rotate changes each list position by the given distance; for a random-access list, its implementation moves elements through cycles.

Limits: The shortcut boxes ints into an ArrayList and uses O(n) extra memory. It rotates a List, not an int[]; an exam asking for block swap will expect the manual routine.

6. Complexity

Manual: O(n) time and O(1) extra space; each element is moved a bounded number of times.

Shortcut: O(n) list rotation and O(n) extra space for boxed elements.

Shortcut complexity: O(n) time and O(n) extra storage for the ArrayList.

7. Edge cases and common mistakes

  • If d ≥ n, reduce it modulo n; if d = 0, leave the array unchanged.
  • Empty arrays must return before taking d % n.
  • This code accepts a negative distance as a right rotation by its absolute amount.

8. Slide alignment

Slides 7–8 correctly show [1, 2, 3, 4, 5] rotated left by 2 as [3, 4, 5, 1, 2]; slide 9’s final [5, 1, 2, 3, 4] does not match that left rotation. Slide 13’s code uses three reversals, and slide 12 uses a temporary array. The manual code here implements block swap and follows the correct left-rotation examples.

9. Self-check

  1. What does a left rotation by 2 do to [1,2,3,4,5]?
    It returns [3,4,5,1,2].
  2. Why normalize d?
    Rotating n places returns the same array, so only d mod n matters.

TOPIC 07

Max product subarray

1. Question

Find a contiguous subarray (a consecutive section of the array) whose elements have the largest product, and return that product.

Sample input

4
2 -2 3 4

Sample output

12

2. Idea in plain words

Keep the largest and smallest product ending at the current position. A negative value can turn the smallest (most negative) product into the largest positive one, so both are needed. The current value itself also starts a new subarray.

At each step compare three candidates: the value alone, value × previous maximum, and value × previous minimum. BigInteger keeps products exact when a long product would overflow.

import java.math.BigInteger;
import java.util.Scanner;

public class Main {
    private static BigInteger larger(BigInteger a, BigInteger b) {
        return a.compareTo(b) >= 0 ? a : b;
    }

    private static BigInteger smaller(BigInteger a, BigInteger b) {
        return a.compareTo(b) <= 0 ? a : b;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();

        if (n <= 0) {
            System.out.println("No subarray");
            return;
        }

        BigInteger[] values = new BigInteger[n];
        for (int i = 0; i < n; i++) {
            values[i] = scanner.nextBigInteger();
        }

        BigInteger maxEnding = values[0];
        BigInteger minEnding = values[0];
        BigInteger best = values[0];

        for (int i = 1; i < n; i++) {
            BigInteger current = values[i];
            BigInteger withMax = current.multiply(maxEnding);
            BigInteger withMin = current.multiply(minEnding);

            // Keep both extremes because a later negative can flip their roles.
            BigInteger nextMax = larger(current, larger(withMax, withMin));
            BigInteger nextMin = smaller(current, smaller(withMax, withMin));
            maxEnding = nextMax;
            minEnding = nextMin;
            best = larger(best, maxEnding);
        }

        System.out.println(best);
    }
}

import java.util.Scanner;

public class Main {

        Scanner scanner = new Scanner(System.in);

2. Idea in plain words

Boyer–Moore cancels different values in pairs. If a majority exists, it cannot be cancelled completely, so one candidate remains. A second pass must count that candidate: the first pass alone does not prove a majority.

It is like removing one vote for each of two different choices. A value with more than half the votes survives every possible set of cancellations.

4. Java code manual · exam version

Manual · exam version
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] values = new int[n];

        for (int i = 0; i < n; i++) {
            values[i] = scanner.nextInt();
        }

        int candidate = 0;
        int count = 0;

        // Cancel one vote whenever the current value differs from the candidate.
        for (int value : values) {
            if (count == 0) {
                candidate = value;
                count = 1;
            } else if (value == candidate) {
                count++;
            } else {
                count--;
            }
        }

        // Boyer-Moore produces a candidate; this pass proves it is a majority.
        int occurrences = 0;
        for (int value : values) {
            if (value == candidate) {
                occurrences++;
            }
        }

        if (occurrences > n / 2) {
            System.out.println(candidate);
        } else {
            System.out.println("No majority element");
        }
    }
}

A palindrome reads the same from both ends. Every character count must be even except possibly one center character. To make the result lexicographically smallest, put the smallest possible half in ascending order on the left; mirror it in reverse on the right.

import java.util.Scanner;
import java.util.Locale;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String text = scanner.nextLine().trim().toLowerCase(Locale.ROOT);
        int[] frequency = new int[26];

        // The slide solution uses an English a-z frequency table.
        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);
            if (ch < 'a' || ch > 'z') {
                throw new IllegalArgumentException("Use English letters a-z");
            }
            frequency[ch - 'a']++;
        }

        int oddCount = 0;
        int middleIndex = -1;
        StringBuilder left = new StringBuilder();

        for (int i = 0; i < frequency.length; i++) {
            if (frequency[i] % 2 != 0) {
                oddCount++;
                middleIndex = i;
            }

            // Half of each count belongs on the left.
            for (int copies = 0; copies < frequency[i] / 2; copies++) {
                left.append((char) ('a' + i));
            }
        }

        if (oddCount > 1) {
            System.out.println("-1");
            return;
        }

        StringBuilder answer = new StringBuilder(left);
        if (oddCount == 1) {
            answer.append((char) ('a' + middleIndex));
        }
        answer.append(new StringBuilder(left).reverse());
        System.out.println(answer);
    }
}
